쿠폰노트 소개

쿠폰노트는 "결제하기 전에 쓸 수 있는 할인코드가 있나?"를 매번 찾아다니지 않도록, 플랫폼별 할인코드·쿠폰·카드사 혜택을 매달 한 페이지에 정리합니다.

운영 원칙

  • 매달 갱신 — 플랫폼 공식 채널에 공개된 혜택만 싣고, 만료된 쿠폰은 자동으로 내립니다.
  • 조건을 숨기지 않음 — 최소 결제금액, 사용 기간, 중복 불가 조건을 함께 적습니다.
  • 가입·설치 요구 없음 — 코드를 복사해서 플랫폼 결제창에 붙여넣기만 하면 됩니다.

수익 구조 안내

공정위 문구

버튼을 눌러 이동한 뒤 구매가 발생하면 플랫폼이 쿠폰노트에 수수료를 지급합니다. 구매자가 내는 가격에는 영향이 없습니다.
